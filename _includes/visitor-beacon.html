{% comment %} Visitor beacon. Worker source and deploy steps: /visitor-log/ Set `visitor_log_endpoint` in _config.yml to the deployed Worker URL, e.g. visitor_log_endpoint: "https://edge-metrics..workers.dev" Until it is set, this include emits nothing at all. Two signals on purpose: - the fires in anything that renders the page, JS or not - the script fires only where JavaScript actually executes A hit on the first but not the second is a fetcher that does not run scripts, which is what an email security gateway usually looks like. The script also sends, via sendBeacon to /e: - one "leave" event per page view (seconds visible, max scroll depth), on the first pagehide / switch to hidden / click that navigates away - one event per click on an outbound link or a file such as a PDF (same-site navigation is already the next page view), at most 10 and, with /collect: a page-view id, a random visitor id kept in localStorage, the browser time zone, language and screen size.
